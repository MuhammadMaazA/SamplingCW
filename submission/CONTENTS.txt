This folder is a copy of what we upload to Moodle for COMP0228 Coursework 1, CW1 Group 06.

The five files are the group report PDF, the code zip, the slides, the data zip and the marker README.
The code zip was made from the committed code with git archive, so the same code is in src, tests and report in this repo.
The data zip holds the recorded sessions that are also in experiments/results.
