This folder is a copy of what we upload to Moodle for COMP0228 Coursework 1, CW1 Group 06.

The five files are the group report PDF, the code zip, the slides, the data zip and the marker README.
The code zip was made from the committed code with git archive. It has src, pyproject.toml and the experiment plans, and leaves out the tests, the report scripts and the markdown files.
The data zip holds the recorded sessions that are also in experiments/results, without the text files.
